## Installation

### Step 1: Clone the Repository
```bash
git clone https://github.com/Neel-max-cpu/Rag-pdf-reader.git
```


### Step 2: Navigate to the Project Directory
Change into the project directory:
```
cd frontend
```

```
cd backend
```

### Step 3: Install Dependencies
Run the following command to install the necessary dependencies for both frontend and backend:
```shell
npm install
```
or 

```shell
npm i
```

### Step 4: Setup .env file
backend
```js
GEMINI_API_KEY=...

```
frontend
```js
NEXT_PUBLIC_BACKEND_URL=...
```

### Usage
After setting up the environment variables, you can start the application.

### Start the app
Run the frontend and backend

```shell
npm run dev
```
